# VegaCut roadmap

Each milestone requires its own build and validation. No user testing is required between 0.1 and 0.2.

| Version | Scope |
|---|---|
| 0.1 | Fork identity, isolated settings, Windows portable packaging, baseline validation |
| 0.2 | Gray theme, media/FX upper left, preview upper right, timeline below, track controls, saved workspaces |
| 0.3 | Vegas-style keyboard/mouse timeline interaction |
| 0.4 | User-reported timeline fixes: A/V detach, click-to-seek and sync offset markers |
| 0.5 | Audio seam/export regression coverage and envelopes |
| 0.6 | Pan/Crop and Track Motion |
| 0.7 | Effect chains and titles |
| 0.8 | Proxy/cache/performance work |
| 0.9 | Render presets, queue and recovery hardening |
| 1.0 | Stabilization of the verified feature set |

Upstream history is preserved in docs/UPSTREAM_ROADMAP.md. Do not equate inherited features with verified parity.

The 0.4 scope was revised following hands-on feedback on 0.3. Automatic overlap crossfades and ripple modes remain future work, not part of this fix release.

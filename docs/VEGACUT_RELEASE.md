# VegaCut v0.2.0

Adds the VegaCut workspace: media/effects tabs at upper left, preview at upper right and a wide timeline below. English and Russian interface only. Neutral gray theme, larger audio headers, volume and pan controls with Undo, and saved workspace support.

VegaCut is an independent Windows x64 fork of FilmCraft with a Vegas-inspired workflow.

Extract the portable ZIP into a writable folder and launch `VegaCut.exe`.
Preferences, autosaves and recovery are kept in the adjacent `data` folder.
The CLI is `VegaCut-cli.exe`; the project format remains `.fcproj`.

Early-development release. No `.veg`, VST3 or OpenFX compatibility is promised.
Automatic replacement is disabled; download new versions from this repository.
See CHANGELOG.md, KNOWN_ISSUES.md and docs/VEGACUT_VALIDATION.md in the source for scope and validation.
